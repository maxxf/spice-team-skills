# Lead Magnet Email Sequences

Auto-generated follow-up emails based on storefront audit score bands.

## How these are governed

Prospect-facing copy, so the canon applies: `references/client-comms-style.md`
for the standard, `references/client-comms-pass.md` for the checks, and the
governor's prospect and sales outreach rule for the shape. Nothing on this page
restates either file.

These are static templates, not per-send drafts. **Run the governor over this
file when the templates change, not on every send.** A pass on the file is a pass
on every message merged from it.

One check does not work that way. The line of specific human attention cannot
live in a template, because a template is by definition the thing that is the
same for everybody. So every email below carries a `{human_line}` slot, and
filling it is the sender's job on every single send. See the note under
Personalization Variables for what counts and what does not.

## Sequence Logic

### Trigger Rules

```python
def get_sequence(score: int) -> str:
    if score < 50:
        return "POOR"
    elif score < 70:
        return "FAIR"
    elif score < 85:
        return "GOOD"
    else:
        return "EXCELLENT"
```

### Personalization Variables

| Variable | Source |
|----------|--------|
| `{brand}` | Audit input |
| `{score}` | Audit output |
| `{first_name}` | CRM / form |
| `{market}` | Audit input |
| `{gap_1}`, `{gap_2}`, `{gap_3}` | Top 3 scoring gaps |
| `{strength_1}`, `{strength_2}` | Top 2 scoring strengths |
| `{impact_X}` | Estimated % lift per gap |
| `{competitor}` | Top local competitor |
| `{projected_monthly_gain}` | ROI calculation |
| `{hero_issue}` | Hero image specific finding |
| `{menu_count}` | Category count |
| `{rating}` | Platform rating |
| `{human_line}` | **Written by hand, every send. See below.** |

**About `{human_line}`.** One sentence that only somebody who actually opened
this restaurant's storefront could have written. Not a merge of the fields above,
which every recipient in the band gets. The test from the canon applies: if you
could swap the brand name and send it to a different restaurant, it isn't the
line. Pull it from the audit screenshots, an odd item on their menu, a review
that says something specific, a location that behaves differently from the rest.
If you can't find one, that's information about how closely you looked, and the
fix is to go look rather than to write something plausible.
